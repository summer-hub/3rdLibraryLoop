# R-19 图形渲染属性继承与重置类

- **状态**: active
- **严重级别**: medium（渐变/填充等渲染效果失效）
- **适用范围**: 使用图形渲染管线（SVG/Canvas）且支持属性继承的库
  - 预筛特征: C++ 代码中含 Draw/InitStyle/InheritAttr 方法；attributes 结构含 gradient/fill/pattern 字段
- **问题本质**: 渲染属性重置逻辑在无 href 引用时也执行了 SetGradient(std::nullopt)，错误清除了从父节点继承的渐变属性——子节点自身没有 href 引用时，渐变应由父节点继承，不应重置
- **检查点**:
  1. 定位所有 SetGradient/SetPattern 等属性重置调用位置
  2. 检查重置前是否判断了"当前节点是否有自身引用"（hasHref），而非无条件重置
  3. 检查继承链：子节点无 href 时，属性是否从父节点正确继承
- **错误特征**: Draw 方法中无条件执行 `SetGradient(std::nullopt, false)` 清除所有渐变；无论 hasHref 真假都重置
- **正确特征**: 仅当 hasFillHref 为 true 时才重置 fill 渐变；仅当 hasStrokeHref 为 true 时才重置 stroke 渐变；无 href 时保留继承值
