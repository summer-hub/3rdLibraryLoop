# R-11 接口/回调实现完整性类

- **状态**: active
- **严重级别**: high（声明的接口未实现，调用方无法获取错误信息）
- **适用范围**: 对外声明了回调接口（onError/onXxx）的库
  - 预筛特征: JS 层类型定义中含 onError/onXxx 回调 prop；ArkTS 层 TurboModule 实现
- **问题本质**: 库对外声明了错误回调接口（如 onLocationError），但鸿蒙侧实现中未触发该回调——错误发生时调用方无法感知，导致静默失败
- **检查点**:
  1. 列出 JS 层类型定义中所有声明的回调 prop（onXxx）
  2. 逐项在 ArkTS 层实现中搜索对应的回调触发代码
  3. 检查错误分支（catch/reject/error callback）中是否调用了声明的错误回调
  4. 检查是否有"声明但未实现"的回调（类型定义有但实现中无任何触发点）
- **错误特征**: JS 层声明了 onLocationError prop，但 ArkTS 层 catch 分支中无任何触发 onLocationError 的代码
- **正确特征**: 每个声明的回调在对应的错误/事件分支中都有触发代码；未实现的回调应在文档中明确标注
