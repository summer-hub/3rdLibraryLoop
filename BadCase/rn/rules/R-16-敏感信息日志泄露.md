# R-16 敏感信息日志泄露类

- **状态**: active
- **严重级别**: high（安全测试不通过，上架审核被拒）
- **适用范围**: 所有鸿蒙化库（任何含日志输出的代码）
  - 预筛特征: 代码中使用 Logger.info/debug/error 或 console.log 打印变量内容
- **问题本质**: 日志中打印了敏感信息（MAC 地址、IP 地址、设备标识等），安全扫描不通过
- **检查点**:
  1. 扫描所有 Logger.info/debug/error 调用，检查是否打印了网络连接数据（netConnection）、配置信息（config）等内容
  2. 检查 JSON.stringify 的参数是否包含敏感字段
  3. 检查是否有打印"仅用于调试"的日志未在发布前移除
- **错误特征**: `Logger.info('events,' + JSON.stringify(events))` 打印网络状态含 MAC/IP；`Logger.info('configure,' + JSON.stringify(config))` 打印配置
- **正确特征**: 日志仅打印非敏感的状态摘要（如 "connected" / "disconnected"），不打印原始数据；或使用条件编译仅在 DEBUG 模式打印
