# R-08 手势/事件注册与冲突处理类

- **状态**: active
- **严重级别**: high（手势冲突导致核心交互失效或崩溃）
- **适用范围**: 使用手势（PanGesture/滑动手势）或嵌套滚动组件的库
  - 预筛特征: ArkTS 层含 .gesture() / PanGesture / onGestureRecognizerJudgeBegin；C++ 层含 registerPanGesture / NODE_EVENT
- **问题本质**: 手势注册缺少防重入保护（同一节点重复绑定手势导致崩溃）、手势冲突未通过 onGestureRecognizerJudgeBegin 仲裁、嵌套滚动组件未配置 NestedScroll 模式导致父子组件无法联动
- **检查点**:
  1. 检查手势注册位置是否有防重入标志（如 isPanGestureRegistered），防止 init() 被多次调用时重复绑定
  2. 检查嵌套滚动场景是否配置了 NestedScrollMode（SELF_FIRST / PARENT_FIRST / PARALLEL）
  3. 检查手势冲突场景是否通过 onGestureRecognizerJudgeBegin 仲裁（CONTINUE / REJECT）
  4. 检查手势相关属性的默认值是否与功能预期一致（如 gestureEnabled 默认应为 true）
- **错误特征**: registerPanGesture() 无防重入标志；嵌套滚动无 NestedScroll 配置；手势冲突无仲裁逻辑；gestureEnabled 默认 false 导致手势整体失效
- **正确特征**: 手势注册前检查 isPanGestureRegistered 标志；嵌套滚动显式配置 NestedScrollMode；手势冲突通过 onGestureRecognizerJudgeBegin 返回 CONTINUE/REJECT；手势开关默认值与功能声明一致
