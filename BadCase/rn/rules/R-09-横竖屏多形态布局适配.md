# R-09 横竖屏/多形态布局适配类

- **状态**: active
- **严重级别**: medium（特定设备形态下 UI 展示异常）
- **适用范围**: 含相机预览/扫码/视频等视觉组件的库
  - 预筛特征: JS 层使用 Dimensions API 或 aspectRatio 样式；组件涉及相机/视频预览
- **问题本质**: 组件布局使用固定宽高比（aspectRatio: 3/4）或固定定位（bottom/top），未检测横竖屏状态动态调整，导致横屏时视图偏移或裁剪
- **检查点**:
  1. 检查视觉组件是否使用固定 aspectRatio 或固定尺寸，而非 flex 自适应
  2. 检查是否通过 Dimensions.get('window') 检测横竖屏状态（width > height）
  3. 检查横竖屏切换时提示文字/遮罩等叠加层定位是否动态调整
  4. 检查是否监听 Dimensions change 事件以响应旋转
- **错误特征**: camera style 固定 `aspectRatio: 3/4`；提示文字固定 `bottom` 定位；无 Dimensions 监听
- **正确特征**: camera 使用 `flex: 1` 自适应；通过 `width > height` 判断横竖屏；叠加层根据 isLandscape 切换 top/bottom 定位
