# R-03 附属操作失败阻断主流程类

- **状态**: active
- **严重级别**: high（附属操作失败导致核心功能不可用）
- **适用范围**: 主流程中包含附属步骤（缩略图、统计、日志、预加载、鉴权预检）的库
  - 预筛特征: 主调用链中存在非核心的网络请求/文件操作/图片处理；错误回调路径中包含附属操作的错误信息
- **问题本质**: 主流程（分享/支付/跳转）中的附属操作（缩略图下载等）失败时，错误被直接传播到主流程错误回调，导致核心功能被非关键步骤阻断
- **检查点**:
  1. 识别库的核心主流程（对外承诺的主功能调用链，如分享、支付、跳转）
  2. 列出主流程中的附属操作（非核心必需的下载/压缩/统计步骤）
  3. 逐项检查附属操作的异常分支：失败时是隔离降级（跳过附属步骤继续主流程）还是直接 reject/callback 错误阻断主流程
  4. 检查附属操作失败是否有用户可感知的降级方案（如无缩略图继续分享）
- **错误特征**: 附属操作的错误字符串直接出现在主流程的 callback("xxx Failed...") 路径上；附属操作 Promise 无 catch
- **正确特征**: 附属操作失败时记录日志、置空附属数据、继续执行主流程；或提供开关允许用户关闭附属功能
