# R-07 C++ 智能指针生命周期管理类

- **状态**: active
- **严重级别**: high（app 崩溃，核心功能不可用）
- **适用范围**: C++ 层使用 shared_ptr/weak_ptr 管理原生节点的库
  - 预筛特征: harmony 目录下 .cpp/.h 文件含 shared_ptr/weak_ptr；析构函数中 reset 或访问 shared_ptr 成员
- **问题本质**: 多线程环境下 shared_ptr 并发访问未加锁，析构函数中访问已被其他线程释放的 shared_ptr，导致 bad_weak_ptr 崩溃
- **检查点**:
  1. 定位所有在析构函数 ~ClassName() 中访问 shared_ptr 成员的位置
  2. 检查 shared_ptr 成员的 getter 方法是否有锁保护（shared_mutex/shared_lock）
  3. 检查 getter 返回前是否进行空指针判断（而非 CHECK 断言导致 abort）
  4. 检查析构函数中 reset shared_ptr 成员前是否先加锁
- **错误特征**: getter 中 `CHECK(ptr != nullptr) << "is null!"`（断言失败直接 abort）；无任何锁保护；析构函数直接 `ptr = nullptr` 无锁
- **正确特征**: getter 使用 `std::shared_lock<std::shared_mutex>` 保护读取；返回前判空并记录日志而非 abort；析构函数使用 `std::unique_lock` 后 reset
