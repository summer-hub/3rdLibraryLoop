# R-14 动画初始化时序与状态同步类

- **状态**: active
- **严重级别**: medium（弹窗/动画出现闪烁，体验问题）
- **适用范围**: 使用 Animated API 或动画库的 UI 组件库
  - 预筛特征: JS/TS 代码中使用 Animated.Value / Animated.timing / requestAnimationFrame；组件含 visible/showContent 等显示状态
- **问题本质**: 动画初始化时 animationValue 保留了上一次动画的终值（如 1.0），导致 content 在 setAnimation 创建 animationStyle 时瞬间显示在最终位置（一帧闪烁），然后 startAnimation 重置 animationValue 到 0 才回到初始位置
- **检查点**:
  1. 检查 visible 状态变化时，是否在 setAnimation 之前先 stopAnimation + setValue(0)
  2. 检查是否使用 animationReady 标志在动画初始化完成前阻止内容渲染
  3. 检查 backdrop 动画是否从 Animated.Value 驱动而非 ref.transitionTo（避免旧框架兼容问题）
  4. 检查组件卸载时是否清理所有 pendingRAF/pendingTimeout/stopAnimation
- **错误特征**: setAnimation 在 animationValue 未重置为 0 时调用；showContent 初始为 true；backdrop 使用 ref.transitionTo
- **正确特征**: 先 stopAnimation → setValue(0) → setAnimation → startAnimation；animationReady 控制渲染时机；backdrop 使用 Animated.Value 驱动
