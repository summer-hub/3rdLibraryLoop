# R-05 模块导入路径规范类

- **状态**: active
- **严重级别**: low（不影响运行，但 IDE 爆红严重伤害开发者体验，引发"库有问题"误判）
- **适用范围**: 所有鸿蒙化库（harmony 目录含 .ets 源码）
  - 预筛特征: harmony 目录下 index.ets/ts.ets 或其他 .ets 文件中 import 路径以 .ets 结尾
- **问题本质**: ArkTS 模块导入路径携带 .ets 文件后缀，运行时可解析但 IDE（DevEco Studio）标红报错，开发者按官方文档接入时误判为三方库故障
- **检查点**:
  1. 扫描 harmony 目录所有 .ets 文件的 import/export from 路径
  2. 检查路径是否以 .ets（或 .ts）后缀结尾
  3. 检查入口文件（index.ets）的导出链路是否全部无后缀
- **错误特征**: `import { X } from './src/main/ets/X.ets'` 或 `export * from './ts.ets'`
- **正确特征**: `import { X } from './src/main/ets/X'`（无后缀）
