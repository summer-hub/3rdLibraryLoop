# R-13 文件/数据编码与格式兼容类

- **状态**: active
- **严重级别**: high（非文本文件读取失败；参数编码错误导致服务端报错）
- **适用范围**: 涉及文件读写或 HTTP 请求体组装的库
  - 预筛特征: 代码中使用 fs.readText/fs.readSync；HTTP 请求中组装 formData 或 body
- **问题本质**: 文件读取使用了仅支持文本的 API（readText）而非通用二进制 API（readSync）；HTTP 请求参数编码方式与数据类型不匹配（字符串被 base64 编码为二进制流）
- **检查点**:
  1. 检查文件读取 API 选择：readText 仅支持文本，readSync 支持所有格式
  2. 检查 HTTP 请求体组装时，字符串参数是否被错误编码（base64 vs utf-8）
  3. 检查文件关闭是否在 finally 块中执行（防止异常时 fd 泄漏）
  4. 检查非路径字符串参数是否与文件流参数使用相同的编码路径
- **错误特征**: `fs.readText(path, ...)` 读取非文本文件；`buffer.alloc(data.length, data, 'base64')` 编码字符串参数
- **正确特征**: `fs.readSync(fd, buf)` 通用读取；`buffer.from(data, 'utf-8')` 编码字符串；`fs.closeSync` 在 finally 中执行
