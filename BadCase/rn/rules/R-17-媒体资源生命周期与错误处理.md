# R-17 媒体资源生命周期与错误处理类

- **状态**: active
- **严重级别**: high（本地视频播放失败；文件描述符泄漏）
- **适用范围**: 涉及媒体播放（AVPlayer/Video）或文件描述符（fd）管理的库
  - 预筛特征: 代码中使用 AVPlayer / media.AVFileDescriptor / fs.openSync / getRawFd；含 play/stop/reset 等生命周期方法
- **问题本质**: 视频播放器在切换源（switchVideo）时重复注册事件监听器导致状态机异常；本地 rawfile 视频通过 getRawFd 获取的 fd offset 不为 0，AVPlayer 不支持 offset!=0 的 fd；文件资源（rawfile fd/fs.File）未在切换源时及时关闭导致泄漏
- **检查点**:
  1. 检查 switchVideo/changeSrc 是否重复调用 bindState 注册事件监听器
  2. 检查本地视频源（asset://）是否拷贝到沙箱再用 file:// 播放，而非直接用 getRawFd 的 fd（offset 问题）
  3. 检查文件资源关闭是否有 pendingClose 机制（旧 fd 在新源加载成功后再关闭）
  4. 检查 url 参数有效性校验（空字符串/undefined 不设置源）
  5. 检查 aboutToDisappear 中是否有 try-catch 保护 release/close 操作
- **错误特征**: switchVideo 中调用 bindState() 重复注册；asset:// 直接 getRawFd 返回 fd 设置 fdSrc；closeRawFd 无 pendingClose 机制
- **正确特征**: bindState 只在 init 时调用一次；asset:// 拷贝到沙箱临时目录后用 file:// URI；旧 fd 在新源 INITIALIZED 后关闭；url 有效性校验；aboutToDisappear 有 try-catch
