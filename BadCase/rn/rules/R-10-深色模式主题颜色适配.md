# R-10 深色模式/主题颜色适配类

- **状态**: active
- **严重级别**: medium（深色模式下 UI 异常，用户体验差）
- **适用范围**: 含 WebView/自定义背景色的库
  - 预筛特征: 代码中设置 backgroundColor / darkMode / forceDark；涉及 Web 组件
- **问题本质**: 深色模式下背景色取值错误——深色模式应使用暗色背景（Color.Black）但错误使用了亮色（Color.White），导致先闪白再变黑
- **检查点**:
  1. 检查深色模式分支中 backgroundColor 取值是否与模式匹配（深色→暗色，浅色→亮色/透明）
  2. 检查是否有深色模式切换时的过渡色处理（避免闪烁）
  3. 检查 WebView/容器组件的背景色是否与内容主题一致
- **错误特征**: `darkMode === On ? Color.White : Color.Transparent`（深色模式用白色背景）
- **正确特征**: `darkMode === On ? Color.Black : Color.Transparent`（深色模式用黑色背景）
