# R-15 状态持久化与重启逻辑一致性类

- **状态**: active
- **严重级别**: high（重启逻辑失效，核心功能不可用）
- **适用范围**: 含状态机/生命周期管理（installMode、restart、allow/disallow）的库
  - 预筛特征: 代码中含 installMode/restartApp/allow/disallow 等方法；存在状态标志位（如 _allowed、_restartInProgress）
- **问题本质**: 状态标志位（如 installMode）在 restartApp 调用时未及时复位，导致条件判断失效——restartApp 中途被 allowRestart 覆盖 installMode 值，但后续判断仍依赖过期的 installMode 值
- **检查点**:
  1. 列出所有持久化状态变量（installMode、_allowed、_restartInProgress），检查其生命周期
  2. 检查 restartApp 流程中 installMode 使用后是否复位（如 ON_NEXT_RESTART 模式完成后 reset 为 -1）
  3. 检查 allow/disallow 状态是否在 allow() 时同步设置 _allowed 标志
  4. 检查 restartApp 是否有防重入保护（_restartInProgress 标志 + 排队机制）
- **错误特征**: restartApp 条件判断 `installMode === 0 || installMode === -1` 但 ON_NEXT_RESTART(1) 分支未复位 installMode；allow() 未设置 _allowed 标志
- **正确特征**: 每种 installMode 分支完成后复位 installMode；allow() 设置 _allowed = true 并处理排队请求；restart 有防重入 + 排队机制
