# R-06 传感器/硬件权限按需获取类

- **状态**: active
- **严重级别**: high（不符合隐私法规，上架审核被拒）
- **适用范围**: 声明使用传感器（加速度、陀螺仪、GPS 等）或硬件权限的库
  - 预筛特征: 代码中调用 sensor API（sensor.on/sensor.off）或权限 API；README 含"传感器""权限"能力声明
- **问题本质**: 传感器/硬件在模块初始化时即打开，而非在业务实际调用时按需开启——隐私合规要求"使用时才获取"，初始化即获取导致上架审核被拒
- **检查点**:
  1. 定位传感器/硬件开启的调用位置（openSensor/start/on 等），确认是否在模块初始化（constructor/init）中执行
  2. 检查是否有按需开启机制：首次 addListener 时开启，全部 removeListener 时关闭
  3. 检查是否有引用计数防重复 open/close（同一 listener 重复添加不应重复 openSensor）
  4. 检查 removeAllListeners 时是否复位计数并补一次 closeSensor
- **错误特征**: openSensor() 在模块顶层或构造函数中直接调用；addListener 每次都 openSensor；removeListener 每次都 closeSensor（无计数）
- **正确特征**: 引用计数管理：count===0 时 openSensor（一次），addListener 时 count++（去重），removeListener 时 count--，count===0 时 closeSensor
