# R-18 能力枚举/配置完整性类

- **状态**: active
- **严重级别**: medium（特定格式/能力无法使用）
- **适用范围**: 对外暴露格式/编码/模式枚举的库
  - 预筛特征: JS/TS 代码中定义 AudioFormatType/VideoFormatType 等枚举；ArkTS 层有对应的格式映射
- **问题本质**: 鸿蒙侧枚举定义遗漏了上游社区支持的格式（如 AAC 编码），导致用户按上游文档配置时无法使用该格式——枚举与上游不对齐
- **检查点**:
  1. 对比上游原库（iOS/Android）的类型定义，列出所有支持的格式枚举值
  2. 逐项在鸿蒙侧枚举定义中确认是否存在对应值
  3. 检查枚举值到鸿蒙系统 API 常量的映射是否完整
- **错误特征**: 上游支持 AAC 格式但鸿蒙侧 AudioFormatHarmonyType 枚举中无 AAC 值
- **正确特征**: 鸿蒙侧枚举值与上游完全对齐；新增枚举值后有对应的系统 API 映射
