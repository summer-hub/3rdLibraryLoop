# 用途：
#   Issue 列表页「仓库名称」列的筛选弹窗中，"三方框架 / 三方库"下拉
#   分类依赖本文件：
#     - 列出的仓库名 → 识别为「三方框架」
#     - 未列出的仓库 → 默认识别为「三方库」
#
# 格式说明（与 internal_developers.txt 管理方式一致）：
#   - 每行一个仓库名
#   - 以 # 开头的行视为注释，空行自动忽略
#   - 不区分大小写
#   - 仅填写仓库名本身，不含组织前缀
#     （如写 openssl，而不是 CPF-ApplicationTPC / openssl）
#
# 如何添加框架：
#   在文件末尾新增一行仓库名，保存后回到页面点击「刷新列表」即生效，
#   无需重启服务。
#
# 如何移除框架：
#   删除对应行，或在该行行首加 # 将其注释掉，刷新列表后即恢复为「三方库」。
