# 文档质量检视检查维度

本文件定义文档质量检视的五个维度、检查项和严重度判定标准。

---

## 维度一：文档完整性（权重 30%）

| 检查项 | 严重度 | 说明 |
|--------|--------|------|
| README 缺失 | Critical | 无 README 或 README 为空，用户无法了解库的基本信息 |
| 鸿蒙化说明缺失 | Critical | 缺少鸿蒙化适配说明文档（ohos/README 或等价文档） |
| API 文档缺失 | Major | 公开接口无文档说明（对照接口规格说明.md） |
| 安装指南缺失 | Major | 缺少鸿蒙化库的安装/引入说明（ohpm install 等） |
| 使用示例缺失 | Major | 缺少使用示例代码或 Demo 工程 |
| 中文文档缺失 | Major | 鸿蒙化库面向中文生态，缺少中文文档（README_zh.md 等） |
| 导出声明文档缺失 | Major | index.ets 导出接口无文档说明 |
| 版本说明缺失 | Minor | 无 CHANGELOG 或版本记录 |
| oh-package.json5 说明缺失 | Minor | 依赖配置文件缺少注释/说明 |
| Demo/示例工程缺失 | Minor | 无完整可运行的示例工程 |

---

## 维度二：文档准确性（权重 25%）

| 检查项 | 严重度 | 说明 |
|--------|--------|------|
| 错误示例代码 | Critical | 示例代码无法运行或有明显错误（导入路径错、API 不存在等） |
| API 签名不一致 | Major | 文档描述与实际代码接口签名不匹配（参数名、类型、返回值） |
| 导出声明与文档不匹配 | Major | index.ets 导出的接口与文档描述不一致 |
| 废弃 API 未标注 | Major | 文档中仍引用已废弃的 API 或已移除的鸿蒙 API |
| 鸿蒙 API 说明与代码不一致 | Major | 文档声称使用某 @ohos.* API 但代码实际使用了不同 API |
| 代码注释与文档矛盾 | Major | JSDoc 注释描述与 README/API 文档描述互相矛盾 |
| 版本号不一致 | Minor | 文档版本号与 oh-package.json5 版本不匹配 |
| 依赖说明与实际不匹配 | Minor | 文档描述的依赖与 oh-package.json5 不匹配 |
| 链接失效 | Minor | 文档中的外部链接无法访问（404 等） |

---

## 维度三：文档易读性（权重 15%）

| 检查项 | 严重度 | 说明 |
|--------|--------|------|
| 结构混乱 | Major | 文档缺少章节划分，内容杂乱无层次 |
| 缺少目录导航 | Minor | 长文档（>500 行）无目录索引 |
| 语言不通顺 | Minor | 表述模糊、语法错误或逻辑不连贯 |
| 缺少图表 | Minor | 复杂流程/架构未用图表说明 |
| 格式不规范 | Minor | Markdown 格式错误（未闭合标签、错误链接语法等） |
| 中英文混杂无规范 | Minor | 同一文档中中英文混杂，未遵循统一语言规范 |
| 术语不一致 | Minor | 同一概念在不同文档中使用不同术语 |

---

## 维度四：代码级文档质量（权重 10%）

| 检查项 | 严重度 | 说明 |
|--------|--------|------|
| 公开接口无 JSDoc | Major | 导出的函数/类/接口缺少 JSDoc/TSDoc 注释 |
| JSDoc 参数描述缺失 | Major | 函数注释中缺少参数说明或返回值说明 |
| 鸿蒙特有 API 未注释 | Major | @ohos.* 调用缺少权限/版本等必要注释 |
| 注释过时 | Minor | 代码变更后注释未同步更新 |
| 注释格式不规范 | Minor | JSDoc 格式不符合 ArkTS 编程规范 |

---

## 维度五：鸿蒙化文档专项（权重 20%）

| 检查项 | 严重度 | 说明 |
|--------|--------|------|
| 权限说明缺失 | Critical | 使用系统 API（如 sensor、network、geolocation）但未说明所需权限 |
| 鸿蒙化构建配置说明缺失 | Major | build-profile.json5 / hvigorfile.ts 中的鸿蒙特有配置未说明 |
| 鸿蒙特性行为说明缺失 | Major | 缺少鸿蒙平台特有行为/限制说明（如线程模型差异） |
| 差异对比文档缺失 | Major | 缺少鸿蒙化与原库的差异说明（行为差异、接口差异） |
| 鸿蒙化迁移指南缺失 | Major | 缺少从原库迁移到鸿蒙化版本的指南 |
| 兼容性说明缺失 | Major | 缺少支持的鸿蒙版本/API 版本范围说明 |
| 鸿蒙化已知限制说明缺失 | Major | 鸿蒙化后存在的已知功能限制未文档化 |
| 性能限制说明缺失 | Minor | 缺少鸿蒙化后的性能差异/瓶颈说明 |
| 鸿蒙化第三方依赖说明缺失 | Minor | oh-package.json5 中的鸿蒙特有依赖未说明用途 |
| 鸿蒙化测试说明缺失 | Minor | 缺少鸿蒙化特有测试方法/环境说明 |

---

## 严重度判定标准

| 严重度 | 扣分 | 判定依据 |
|--------|------|----------|
| Critical | -15 分/项 | 导致用户完全无法使用或严重误解库的功能 |
| Major | -8 分/项 | 关键信息缺失或错误，显著影响用户使用体验 |
| Minor | -3 分/项 | 描述不精确但不影响核心使用 |
