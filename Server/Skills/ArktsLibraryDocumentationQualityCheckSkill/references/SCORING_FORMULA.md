# 评分公式与等级标准

本文件定义文档质量检视的评分计算公式、严苛扣分保障和等级标准。

---

## 一、各维度子评分计算

每个维度独立计算子评分（0-100）：

```
维度子评分 = max(0, 100 - 该维度 Critical扣分 - 该维度 Major扣分 - 该维度 Minor扣分)

各级别扣分标准（同一维度内叠加）：
- Critical 级别：每项 -15 分
- Major 级别：每项 -8 分
- Minor 级别：每项 -3 分
```

---

## 二、综合评分计算

```
综合评分 = max(0, round(
  完整性子评分 × 0.30 +
  准确性子评分 × 0.25 +
  易读性子评分 × 0.15 +
  代码级文档子评分 × 0.10 +
  鸿蒙化专项子评分 × 0.20
))
```

---

## 三、严苛扣分上限保障

为防止极端情况下评分虚高，设置总体扣分下限：

```
总扣分 = 100 - 综合评分
若存在 ≥3 个 Critical 问题，总扣分最低为 40 分（综合评分最高 60）
若存在 ≥1 个 Critical 且 ≥5 个 Major，总扣分最低为 50 分（综合评分最高 50）
```

---

## 四、评分等级标准

| 评分区间 | 等级 | 含义 |
|----------|------|------|
| 90-100 | 优秀 | 文档完善、准确、易读，鸿蒙化说明充分 |
| 80-89 | 良好 | 存在少量 Minor 问题，不影响使用 |
| 70-79 | 一般 | 存在 Major 级别文档缺失，需补充 |
| 60-69 | 较差 | 关键文档缺失或不准确，严重影响使用 |
| 50-59 | 不合格 | Critical 级别文档缺失，用户无法正常使用 |
| <50 | 严重不足 | 多维度 Critical 问题，文档基本不可用 |
