# 报告格式模板

本文档定义 RNLibraryTestCoverageCheckSkill 最终输出报告 `用例覆盖度检视报告.md` 的格式模板。

---

## 格式要求

> ⚠️ **关键格式约束**：
> 1. 综合评分必须使用 `**综合评分：XX/100**` 格式（粗体标记、中文冒号）
> 2. 每个维度必须包含 `**维度评分：XX/100**` 格式
> 3. 覆盖度明细必须列出每个公开接口的覆盖状态
> 4. 评分正则匹配优先级：`综合评分` > `总体评分/评分` > `得分`

---

## 评分等级说明

| 分数区间 | 等级 | 说明 |
|----------|------|------|
| 90-100 分 | 优秀 | 接口覆盖率高、测试质量好 |
| 80-89 分 | 良好 | 主要接口有测试，质量尚可 |
| 70-79 分 | 一般 | 部分接口有测试，测试质量有不足 |
| 60-69 分 | 较差 | 覆盖率低或测试质量差 |
| 50-59 分 | 严重不足 | 核心接口缺少测试保障 |
| <50 分 | 不可用 | 触发归零规则或几乎所有接口无测试 |
| 0 分 | 完全缺失 | 无任何测试或触发归零规则 |

> ⚠️ **严苛标准**：测试覆盖度是库质量的最后防线。80 分以下即存在明显测试不足，50 分以下视为严重不可用。

---

## 严重度映射

| 严重度 | 扣分范围 | 说明 |
|--------|----------|------|
| **Critical** | ≥ 10 分 | 致命问题，核心接口无测试 |
| **Major** | 5-9 分 | 严重问题，重要测试缺失或测试质量差 |
| **Minor** | ≤ 4 分 | 轻微问题，测试规范性不足 |

---

## 维度子评分计算

每个维度独立计算子评分（用于报告中明细展示）：

```
维度子评分 = (维度得分 / 基础分) × 100
```

例如：公开接口覆盖率维度得分 42/70，则维度子评分 = (42/70) × 100 = 60/100
