# 稳定性检视报告模板

> 本模板为 `arkts-library-stability-check` 的最终输出模板。生成报告时**严格遵循此格式**，替换 `{占位符}` 内容。
>
> ⚠️ **后端解析依赖**：报告必须包含 `**综合评分：XX/100**` 格式（粗体标记、中文冒号），以便后端 `_parseArktsLibraryScore` 函数正确解析评分。

## 填充说明

| 占位符 | 说明 |
|--------|------|
| `{repoName}` | 仓库名称（来自任务参数） |
| `{timestamp}` | 报告生成时间 |
| `{fileCount}` | 实际检视的核心文件数 |
| `{score}` | 综合评分（0-100） |
| `{扣分}` / `{得分}` | 各维度扣分与得分 |
| `{count}` | 各扫描维度的文件数 |

## 评分等级速查

| 分数段 | 等级 | 说明 |
|--------|------|------|
| 90-100 | 优秀 | 异常处理完善，资源管理规范，无稳定性风险 |
| 80-89 | 良好 | 存在少量 Minor 问题，不影响核心稳定性 |
| 70-79 | 一般 | 存在 Major 级别问题需关注，有一定风险 |
| 60-69 | 较差 | 存在 Critical 级别问题，稳定性堪忧 |
| <60 | 严重不足 | 多个 Critical 问题，崩溃/泄露风险极高 |
| 0 | 不可用 | 触发归零规则或完全缺失稳定性设计 |
