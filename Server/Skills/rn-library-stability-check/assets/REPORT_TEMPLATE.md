## 报告格式约束

> **重要**：报告必须包含 `**综合评分：XX/100**` 格式（粗体标记、中文冒号），且评分值位于"二、综合评分"章节，确保可被 `_parseRNLibraryScore` 函数正确解析。评分正则匹配优先级为 `综合评分` > `总体评分/评分` > `得分`。
