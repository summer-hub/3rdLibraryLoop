## 关键格式要求

> ⚠️ 以下格式要求必须严格遵守，后端 `_parseArktsLibraryScore` 依赖自动解析。

1. **综合评分行格式**：`**综合评分：数字/100**`
   - 数字为 0-100 的整数
   - 冒号使用**中文全角冒号** `：`
   - 必须出现在"二、综合评分"章节的首行

2. **维度评分明细表**：必须在综合评分之后紧邻展示

3. **各维度子评分标注**：每个维度详情末尾必须标注 `> {维度}子评分：{分数}/100`

## 评分等级参考

| 评分区间 | 等级 | 含义 |
|----------|------|------|
| 90-100 | 优秀 | 文档完善、准确、易读，鸿蒙化说明充分 |
| 80-89 | 良好 | 存在少量 Minor 问题，不影响使用 |
| 70-79 | 一般 | 存在 Major 级别文档缺失，需补充 |
| 60-69 | 较差 | 关键文档缺失或不准确，严重影响使用 |
| 50-59 | 不合格 | Critical 级别文档缺失，用户无法正常使用 |
| <50 | 严重不足 | 多维度 Critical 问题，文档基本不可用 |
