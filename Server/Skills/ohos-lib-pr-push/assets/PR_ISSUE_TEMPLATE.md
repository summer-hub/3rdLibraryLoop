# PR / Issue / 报告模板（ohos-lib-pr-push）

本文件包含三段模板：Issue body、PR body、最终报告。`{占位符}` 由执行时填充。

---

## 一、Issue Body 模板

```markdown
## {一句话说明本次提交的作用}

对 `{owner}/{repo}` 的自动修改提交。

### 提交作用

{2-5 句说明：为什么改、解决什么问题、达到什么效果}

### 修改点

| 序号 | 文件路径 | 修改类型 | 修改说明 |
|------|---------|---------|---------|
| 1 | {path} | 新增/修改/删除 | {具体修改说明} |

### 验证情况

{如有：测试用例执行结果、编译/覆盖率数据；如无写"见 PR CI"}

---
> 此 Issue 由 ohos-lib-pr-push 工作流自动创建
```

---

## 二、PR Body 模板

```markdown
## {一句话说明本次提交的作用}

### 修改内容

{2-5 句概述}

### 修改文件列表

| 序号 | 文件路径 | 修改类型 | 修改说明 |
|------|---------|---------|---------|
| 1 | {path} | 新增/修改/删除 | {具体修改说明} |

### 关联 Issue

Closes #{issue_number}

---
> 此 PR 由 ohos-lib-pr-push 工作流自动生成
```

> **必须**：`Closes #{issue_number}` 在创建 PR 时写入 body，不做事后 PATCH。

---

## 三、最终报告模板（ohos-lib-pr-push-report.md）

```markdown
# 三方库自动提 PR 报告

## 基本信息

| 项目 | 内容 |
|------|------|
| 目标仓库 | {repoUrl} |
| 提交模式 | 直推 / Fork |
| 工作分支 | {branchName} |
| 目标分支 | {defaultBranch} |
| 执行时间 | {currentTime} |

## 执行结果

| 项目 | 内容 |
|------|------|
| 状态 | 成功 / 失败（{失败阶段}） |
| PR 地址 | {prUrl} |
| PR 编号 | !{prNumber} |
| Issue 地址 | {issueUrl} |
| Issue 编号 | #{issueNumber} |
| Issue 绑定 | 是 / 否（PR body 含 `Closes #{issueNumber}`） |
| CI 触发 | 是 / 否（评论 `Start build` 于原仓库 PR） |
| CHANGELOG | 已更新（条目含 Issue 链接）/ 跳过（未修改三方库本身内容） |

## 修改文件清单

| 序号 | 文件路径 | 修改类型 | 修改说明 |
|------|---------|---------|---------|
| 1 | {path} | 新增/修改/删除 | {具体修改说明} |

## CHANGELOG 更新

{判定为"需要"时：写入 CHANGELOG.md 的条目原文（含 Issue 链接）；判定为"不需要"时：跳过原因，如"本次仅修改文档，未修改三方库本身内容"}

## 错误信息

{如有失败步骤：失败阶段、原因、已完成的产物编号与链接}
```
