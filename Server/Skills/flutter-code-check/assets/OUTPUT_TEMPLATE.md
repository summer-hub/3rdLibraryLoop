## 问题等级定义

| 等级 | 图标 | 说明 |
|------|------|------|
| 严重 (CRITICAL) | 🔴 | 必须修复，否则会导致功能缺陷或安全问题 |
| 主要 (MAJOR) | 🟠 | 强烈建议修复，影响代码质量或可维护性 |
| 次要 (MINOR) | 🟡 | 建议改进，优化代码风格或实现方式 |
| 建议 (SUGGEST) | 🔵 | 可选改进，提升代码可读性或文档完整性 |

| 结论 | 条件 |

| REJECTED | 存在多个严重问题或安全缺陷，不建议合并 |
