# 文件类型识别指南

本文档说明如何识别和分类 PR 中修改的文件类型。

---

## 文件类型分类

| 扩展名 | 类型 | 检视重点 |
|--------|------|----------|
| `.ets` | ArkTS 源文件 | 语言约束、装饰器、UI 逻辑 |
| `.ts` | TypeScript | 类型安全、异步、事件监听 |
| `CMakeLists.txt` / `*.cmake` | 构建系统 | Native 模块构建依赖 |
| `build-profile.json5` | 工程配置 | API Level、签名 |
| `oh-package.json5` | 包依赖 | 依赖版本、新增依赖合理性 |
| `module.json5` / `app.json5` | 模块配置 | 权限申请、minAPIVersion |

---

## 改动性质分类

| 性质 | 说明 |
|------|------|
| 新增功能 | 新增 API、组件、模块 |
| 功能修复 | Bug 修复、逻辑修正 |
| 功能优化 | 性能优化、重构 |
| 配置更新 | 依赖、版本、权限变更 |
| 文档更新 | 注释、README、文档 |
| 测试补充 | 单元测试、集成测试 |
