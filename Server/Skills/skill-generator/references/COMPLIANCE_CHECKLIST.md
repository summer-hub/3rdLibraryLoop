# 合规检查清单

> SKILL生成后的完整合规性自检清单。

---

## 1. Frontmatter 检查

| # | 检查项 | 规则 | 通过条件 |
|---|--------|------|----------|
| 1.1 | `name` 存在 | frontmatter 必须有 name 字段 | ✅ 存在 |
| 1.2 | `name` 字符集 | 仅 `a-z`/`0-9`/`-` | ✅ 无大写/特殊字符 |
| 1.3 | `name` 长度 | 1-64 字符 | ✅ 在范围内 |
| 1.4 | `name` 首尾 | 不以 `-` 开头或结尾 | ✅ 合规 |
| 1.5 | `name` 连续 | 无连续 `--` | ✅ 合规 |
| 1.6 | `name` 匹配目录 | name === 父目录名 | ✅ 匹配 |
| 1.7 | `description` 存在 | 必须有 description | ✅ 存在 |
| 1.8 | `description` 长度 | ≤1024 字符 | ✅ 在范围内 |
| 1.9 | `description` 内容 | 含"做什么"+"何时用"+关键词 | ✅ 三要素齐全 |
| 1.10 | `license` 存在 | 推荐有 license | ✅ 存在 |
| 1.11 | `metadata.author` | 推荐有 author | ✅ 存在 |
| 1.12 | `metadata.version` | 推荐有 version | ✅ 存在 |

## 5. 自动化校验

运行校验脚本执行上述检查（跨平台，仅需 Node.js）：

```bash
node {skillDir}/scripts/validate-skill.cjs {skillDir}
```

脚本输出 `ALL CHECKS PASSED` 表示全部通过，否则列出失败项。
