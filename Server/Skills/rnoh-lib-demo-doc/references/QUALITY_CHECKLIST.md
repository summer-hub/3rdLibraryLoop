## 8. 自动化校验

可运行校验脚本对生成的 Demo 描述文档执行结构检查：

```bash
bash {{skillDir}}/scripts/validate-demo-doc.sh {{outputPath}}
```

脚本检查项：
- 文件存在且非空
- 包含必需章节（概述、Demo 总览、Demo 描述列表、接口覆盖矩阵）
- 表格结构完整（列数正确）
- 序号连续性
- 无"未覆盖"状态
- 双计数器关键词检测（callCount/callbackCount）

输出 `ALL CHECKS PASSED` 表示全部通过，否则列出失败项。
