## 报告生成说明

1. **文件命名**：必须为 `check-report.md`
2. **保存路径**：必须在 `{outputDir}` 下
3. **文件列表**：同时生成 `changed-files.txt`（每行一个文件路径）
4. **无鸿蒙变更**：若 PR 只修改 `android/` 或 `ios/`，在报告中注明"本次 PR 无鸿蒙平台代码变更"并给出 APPROVED
5. **线程安全优先**：对 C++ CAPI 的内存安全和线程安全问题给予最高优先级标记为 CRITICAL

---

**问题等级定义**：

- 🔴 **CRITICAL（严重）**：会导致崩溃、数据损坏、安全漏洞的严重问题，必须修复
- 🟠 **MAJOR（主要）**：影响功能正确性、性能、兼容性的重要问题，强烈建议修复
- 🟡 **MINOR（次要）**：代码质量问题、规范问题、可读性问题，建议修复
- 🔵 **SUGGEST（建议）**：可选的改进建议，不强制要求修复
